## STEP 5 — Convert all 6 pages

Read each HTML file and extract only the `<main>...</main>` content. Convert to JSX. Do not include aside/header/footer in any page — those are in Shell.tsx.

### JSX conversion rules:
- `class=` → `className=`
- `for=` → `htmlFor=`
- Self-close void elements: `<input />`, `<br />`
- Inline style hyphens: `style={{ fontVariationSettings: "'FILL' 1" }}`
- Keep ALL Tailwind classes exactly as written — do not modify any className
- `href="#"` → `<Link href="[correct route]">` using next/link

### DESIGN.md component rules to enforce during conversion:

**Terminal Cards** — every card must have:
- Window header with filename (top-left) + 3 circle controls (top-right)
- `rounded-none` on the container (0px radius per DESIGN.md)
- Thin bottom border separating header from content

**Buttons (Commands)** per DESIGN.md:
- Primary: `bg-primary-container text-on-primary-container` + `hover:shadow-glow-cyan` — text prefixed with `>`
- Secondary: ghost with `border border-secondary-fixed-dim text-secondary-fixed-dim hover:bg-secondary/10` — text prefixed with `>`
- Never use rounded-lg on buttons — use `rounded` (4px) per DESIGN.md "Soft" shape rule

**CLI Badges (Flags)** per DESIGN.md:
- `bg-brand-container border border-primary-container text-primary-fixed-dim`
- `rounded-full` (pill shape)
- Text format: `--flag-name`

**Input fields** per DESIGN.md:
- Use `.terminal-input` class from globals.css
- Prefix with `guest@rudresh:~$` span in `text-primary font-bold`
- Bottom border only, cyan on focus

**Elevation** per DESIGN.md:
- No `drop-shadow` or `shadow-md/lg` anywhere
- Active/focused elements only: `.terminal-glow` or `shadow-glow-cyan`
- Glassmorphism (`.glass`) only on dropdowns/tooltips, nowhere else
