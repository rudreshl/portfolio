Create a mode selection splash screen that appears when the user first visits 
the portfolio. It asks whether they want Voice Assistant mode or Traditional 
browsing mode. This must feel native to the existing terminal OS design system.

---

## Files to create
- components/ModeSelector.tsx   ← the splash UI
- hooks/usePortfolioMode.ts     ← stores and reads the mode choice

---

## Behavior

On first visit to "/" (home page only):
- Show the ModeSelector fullscreen overlay before any content loads
- Once user picks a mode, store it in localStorage key "rl_portfolio_mode"
- Value is either "voice" or "traditional"
- Never show the splash again on subsequent visits or page navigations
- If localStorage already has a value, skip splash entirely and go straight 
  to the site

If user picks "traditional" → dismiss overlay, show site normally, 
  VoiceAssistant component stays hidden forever for this session
If user picks "voice" → dismiss overlay, show site, VoiceAssistant 
  component becomes visible and auto-opens

## hooks/usePortfolioMode.ts

```ts
'use client'
import { useState, useEffect } from 'react'

type Mode = 'voice' | 'traditional' | null

export function usePortfolioMode() {
  const [mode, setMode] = useState<Mode>(null)
  const [isDecided, setIsDecided] = useState(false)

  useEffect(() => {
    const stored = localStorage.getItem('rl_portfolio_mode') as Mode
    if (stored === 'voice' || stored === 'traditional') {
      setMode(stored)
      setIsDecided(true)
    }
  }, [])

  const chooseMode = (chosen: 'voice' | 'traditional') => {
    localStorage.setItem('rl_portfolio_mode', chosen)
    setMode(chosen)
    setIsDecided(true)
  }

  const resetMode = () => {
    localStorage.removeItem('rl_portfolio_mode')
    setMode(null)
    setIsDecided(false)
  }

  return { mode, isDecided, chooseMode, resetMode }
}
```
